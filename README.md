# The Excuse That Almost Works

A one-line excuse a gamer texts their boss to skip work on GTA 6 launch week: the building lift is out, the courier won't carry the box up six flights, so they're stuck waiting downstairs. Boring, specific, and almost believable — the kind of mundane logistics snag a tired manager has heard before.
